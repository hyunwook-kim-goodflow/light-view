Visits are counted with Cloudflare Web Analytics, which keeps **aggregate data only** (page address, referring address, browser type, country), uses no cookies or browser storage and does not track individual visitors. Cloudflare processes this data ([Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/)).

The site loads no outside fonts. The download buttons fetch the files from GitHub (github.com).

The light-view program never contacts this website. With the update check on, it asks GitHub only, as described under "The program" above.
