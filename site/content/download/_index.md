## 설치판: 두 가지 방식

설치 첫 화면에서 골라요. 기본은 **나만 사용**이에요.

| | 나만 사용 (기본) | 모든 사용자 |
|---|---|---|
| 관리자 권한 | 필요 없어요 | 필요해요 (UAC 창) |
| 설치 폴더 | `%LOCALAPPDATA%\Programs\light-view` | `C:\Program Files\light-view` |
| 탐색기 HEIC 썸네일 | 있어요 | 있어요 |
| 탐색기 미리 보기 창 | 없어요 | 있어요 |
| 자세히 탭 (해상도, 찍은 날짜, 카메라) | 없어요 | 있어요 |

두 방식 모두 시작 메뉴 바로가기와 "연결 프로그램" 등록을 하고, 제거 프로그램이 있어요. Windows 10/11은 프로그램이 스스로 기본 앱이 될 수 없어서, 설치 마지막 화면의 **기본 앱 설정 열기**에서 light-view를 골라요.

## 포터블판

zip을 아무 폴더에 풀고 `light-view.exe`를 실행해요. 설정은 exe 옆 `data` 폴더에 저장하고 레지스트리는 보통 건드리지 않아요. 탐색기 썸네일은 없어요.

## "Windows의 PC 보호" 창이 뜨면

코드 서명 전 릴리스는 처음 실행할 때 SmartScreen 창이 뜰 수 있어요. 아래처럼 체크섬을 먼저 확인한 다음 **추가 정보** → **실행**을 눌러요. zip에서 푼 파일에 경고가 뜨면 zip 파일의 속성에서 **차단 해제**를 체크하고 다시 풀어요.
