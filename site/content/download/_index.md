## 설치판은 두 가지 방식이 있습니다

설치 첫 화면에서 고릅니다. 기본은 **나만 사용**입니다.

| | 나만 사용 (기본) | 모든 사용자 |
|---|---|---|
| 관리자 권한 | 필요 없음 | 필요 (UAC 창) |
| 설치 폴더 | `%LOCALAPPDATA%\Programs\light-view` | `C:\Program Files\light-view` |
| 탐색기 HEIC 썸네일 | 있음 | 있음 |
| 탐색기 미리 보기 창 | 없음 | 있음 |
| 자세히 탭 (해상도, 찍은 날짜, 카메라) | 없음 | 있음 |

두 방식 모두 시작 메뉴 바로가기와 "연결 프로그램" 등록을 하고, 제거 프로그램을 함께 설치합니다. Windows 10/11에서는 프로그램이 스스로 기본 앱이 될 수 없으므로, 설치 마지막 화면의 **light-view를 기본 사진 앱으로 지정**을 켠 채 마치고, 열리는 Windows 설정에서 **기본값 설정**을 한 번 눌러 주세요.

## 포터블판은 설치 없이 씁니다

zip을 아무 폴더에 풀고 `light-view.exe`를 실행하면 됩니다. 설정은 exe 옆 `data` 폴더에 저장하고, 레지스트리는 보통 건드리지 않습니다. 탐색기 썸네일은 없습니다.

## "Windows의 PC 보호" 창이 뜬다면

코드 서명이 없는 릴리스라 처음 실행할 때 SmartScreen 창이 뜰 수 있습니다. 아래 "받은 파일 확인하기"에서 체크섬을 먼저 확인한 다음 **추가 정보** → **실행**을 누르면 됩니다. zip에서 푼 파일에 경고가 뜨면 zip 파일 속성에서 **차단 해제**를 체크하고 다시 풀어 주세요.
