## 한국어

### 새로운 것

- **탐색기 HEIC/HEIF 썸네일:** 설치판을 쓰면 탐색기에서 아이폰 사진(HEIC·HEIF)이 빈 아이콘 대신 사진으로 보여요.
- **두 가지 설치 방식:** 설치 첫 화면에서 **나만 사용**(기본, 관리자 권한 없음)과 **모든 사용자**(관리자 권한) 중에서 골라요.
- **미리 보기 창과 자세히 탭(모든 사용자 설치):** 탐색기 미리 보기 창에 HEIC가 크게 보이고, 파일 속성 "자세히" 탭에 해상도·찍은 날짜·카메라 제조사와 모델이 나와요. 위치 정보는 내보내지 않아요.

### 바뀐 것

- 탐색기 확장은 사진을 직접 해석하지 않고, 앱과 같은 격리된 작업자 프로세스에 맡겨요.
- 업데이트·제거할 때 탐색기를 닫거나 다시 시작하지 않아요. 쓰던 옛 확장 파일은 다음 로그인 때 지워져요.
- 다른 프로그램이 등록해 둔 HEIC 처리기가 있으면 설치 때 저장해 두었다가 제거할 때 되돌려요.

### 알려진 문제

- 내장 썸네일이 없는 12 MP HEIC는 썸네일 한 장에 300 ms 넘게 걸릴 수 있어요(배터리 전원에서 측정).
- 나만 사용 설치에서는 미리 보기 창과 자세히 탭이 없어요(Windows가 사용자별 등록을 읽지 않아요).
- 미리 보기 창은 창 크기를 바꿔도 다시 그리지 않아요.
- 코드 서명 전 릴리스라서 처음 실행할 때 SmartScreen 경고가 뜰 수 있고, 모든 사용자 설치의 UAC 창에 "알 수 없는 게시자"가 나와요.

## English

### New

- **HEIC/HEIF thumbnails in Explorer:** with the installed copy, Explorer shows iPhone photos (HEIC, HEIF) as pictures instead of blank icons.
- **Two install modes:** the installer's first page offers **for me only** (the default, no administrator rights) or **for all users** (administrator rights).
- **Preview pane and Details tab (all-users install):** Explorer's preview pane shows HEIC photos, and the file's Details tab shows the size, date taken and camera make and model. Location data is never exposed.

### Changed

- The Explorer extension does not decode photos itself; it hands them to the same sandboxed worker process as the app.
- Updating or uninstalling never closes or restarts Explorer. An old extension file still in use is removed at the next sign-in.
- If another program had registered a HEIC handler, the installer saves it and puts it back on uninstall.

### Known issues

- A 12 MP HEIC without an embedded thumbnail can take more than 300 ms per thumbnail (measured on battery power).
- The for-me-only install has no preview pane or Details tab (Windows does not read per-user registrations for them).
- The preview pane does not redraw when its window is resized.
- Releases before code signing can show a SmartScreen warning on first run, and the all-users UAC prompt names an unknown publisher.
