## 한국어

### 새로운 것

- **.ithmb 파일 열기:** 아이튠즈가 아이폰·애플 TV와 사진을 동기화할 때 만든 `iPod Photo Cache` 폴더의 `.ithmb` 파일을 엽니다. 안은 JPEG 사진이라, 좌우로 넘기기·회전·크기 조정·EXIF 보기가 JPEG와 똑같이 됩니다.
- **탐색기 썸네일과 미리 보기 창(설치판):** 설치하면 `.ithmb`도 그림 파일로 등록되어 탐색기가 Windows 기본 그림 처리기로 썸네일과 미리 보기 창을 보여 줍니다. 나만 사용 설치에서도 됩니다.
- `.ithmb`도 "연결 프로그램" 목록과 우클릭 "light-view로 크기 조정" 메뉴에 들어갑니다.

### 알려진 문제

- 아주 옛 아이팟이 만든 원시 픽셀 방식의 `.ithmb`는 열지 못하고 "열 수 없는 형식"으로 안내합니다.
- `.ithmb`는 기기에 맞춰 줄인 사진이라 원본보다 해상도가 낮을 수 있습니다.
- 코드 서명이 없는 릴리스라 처음 실행할 때 SmartScreen 경고가 뜰 수 있고, 모든 사용자 설치의 UAC 창에 "알 수 없는 게시자"가 나옵니다.

## English

### New

- **Open .ithmb files:** light-view opens the `.ithmb` files in the `iPod Photo Cache` folder iTunes makes when it syncs photos to an iPhone or Apple TV. They are JPEG photos inside, so flipping, rotating, resizing and the EXIF card work as for JPEG.
- **Explorer thumbnails and preview pane (installed copy):** the installer registers `.ithmb` as an image, so Explorer shows thumbnails and the preview pane with Windows' own image handlers, also in the for-me-only install.
- `.ithmb` is added to "Open with" and to the right-click "Resize with light-view" menu.

### Known issues

- Raw-pixel `.ithmb` files from very old iPods do not open; light-view says the format is not supported.
- `.ithmb` photos were resized for the device, so they can be smaller than the originals.
- Releases are not code-signed yet, so SmartScreen may warn on first run, and the all-users install's UAC prompt names an unknown publisher.
