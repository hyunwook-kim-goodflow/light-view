# light-view 로드맵

**Spec:** `docs/superpowers/specs/2026-10-26-light-view-design.md`

설계 문서는 서로 독립적인 하위 시스템 다섯 개를 담고 있다. 각 마일스톤은 그 자체로 실행해 볼 수 있는 소프트웨어를 남기고, 마일스톤마다 별도의 구현 계획을 쓴다. 다음 마일스톤의 계획은 앞 마일스톤이 끝난 뒤, 실제 코드의 인터페이스를 보고 쓴다.

| # | 마일스톤 | 끝나면 되는 것 | Spec 절 | 계획 |
|---|---|---|---|---|
| M1 | 핵심 뷰어 | 더블클릭으로 JPEG·PNG·GIF·WebP·BMP를 열고, 넘기고, 확대/이동한다. 몰입형 goodflow 화면, 메뉴 고정, 라이트/다크, 창 상태 기억, 한 창에서 열기 | §3, §4.1–4.5, §4.8, §5.1, §5.2(HEIF·색 관리 제외), §5.3(상한 검사만) | `2026-10-26-light-view-m1-core-viewer.md` |
| M2 | HEIC와 격리 작업자 | 격리된 작업자 프로세스에서 HEIC를 연다. ICC/nclx → sRGB 색 관리 | §3, §5.2, §6.1, §6.2 | M1 후 작성 |
| M3 | 파일 작업 | 파일 정체성 검사, 긴 경로, 휴지통 삭제와 실행 취소, 무손실 회전 저장(JPEG transupp은 작업자에서, HEIF는 irot 편집), 저장 확인 대화상자 | §5.4–5.6 | M2 후 작성 |
| M4 | 정보와 설정 | EXIF 카드와 전체 보기, 토스트, 오른쪽 클릭 메뉴, 빈 시작 화면, 설정 창, 한국어/영어 | §4.3a, §4.6, §4.7, §4.9 | M3 후 작성 |
| M5 | 강화와 배포 | 타일 렌더링·밉맵·축소 디코딩, 퍼징, CI(audit/deny), 벤치마크, 설치 파일, 포터블, 업데이트 확인, 라이선스 고지, SECURITY.md, SignPath 연결 지점 | §5.3, §6.3–6.7, §7, §9 | M4 후 작성 |

M2와 M3는 같은 작업자 프로세스를 쓰므로 순서를 바꾸지 않는다. M4와 M5의 일부(CI, SECURITY.md)는 M1 직후에 따로 당겨도 된다.
